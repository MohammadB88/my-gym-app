Exercise images for Day 1
=========================

Drop an image into this folder using the exact filename below and it will
appear automatically in the app (no code changes needed). Until a file
exists, the app shows an "Image coming soon" placeholder.

Recommended: landscape photos, roughly 16:9, JPG format.

Expected filenames:

  01-lat-pulldown.jpg        Neutral-Grip Lat Pulldown Machine
  02-chest-press.jpg         Machine Chest Press
  03-hip-thrust.jpg          Hip Thrust / Glute Bridge Machine
  04-lying-leg-curl.jpg      Lying Leg Curl
  05-reverse-pec-deck.jpg    Reverse Pec Deck / Rear-Delt
  06-overhead-press.jpg      Seated Overhead Press
  07-leg-extension.jpg       Seated Leg Extension
  08-hip-abductor.jpg        Hip Abductor Machine
  09-hip-adductor.jpg        Hip Adductor Machine
  10a-biceps-curl.jpg        Machine Biceps Curl
  10b-triceps-extension.jpg  Triceps Extension / Pressdown
  11-pallof-press.jpg        Pallof Press / Dead Bug

If you'd rather use PNG (or another extension), update the matching `img:`
path in index.html.
