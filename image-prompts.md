# Exercise Image Prompts — 3-Day Plan

Prompts for generating the exercise-machine images used on each workout card,
**split one file per day** so you can paste a single day into an AI image tool at
once. Each file is self-contained (it repeats the shared style/negative rules and
numbering note).

| Day | File | Prompts |
|-----|------|---------|
| Day 1 — Full-Body | [`image-prompts/day1.md`](image-prompts/day1.md) | D1-01 … D1-12 |
| Day 2 — Push/Pull + Posterior | [`image-prompts/day2.md`](image-prompts/day2.md) | D2-01 … D2-12 |
| Day 3 — Strength + Control | [`image-prompts/day3.md`](image-prompts/day3.md) | D3-01 … D3-12 |

**How to use:** open a day's file, paste its prompts into an image generator, then
save each output to the file path shown directly under its heading (e.g.
`docs/images/d1/01-lat-pulldown.jpg`). The app picks up a matching file
automatically — until then it shows an "Image coming soon" placeholder.

**Key rules (spelled out in each day file):** equipment only, no people; images
are AI-generated and safe to bundle (don't substitute copyrighted manufacturer
photos); each machine prompt matches the Technogym machine linked from its card.
