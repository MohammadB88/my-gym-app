# Exercise Image Prompts — Core B (Oblique Emphasis)

Prompts for generating exercise images for **Core B** of the training plan.
Generate each with an AI image tool and save it to the path shown in its
heading; the app picks it up automatically. This file is self-contained —
paste the whole thing into an image generator. (Core A has its own file.)

All five exercises are bodyweight mat work with no machines, so each image is
a clean, empty exercise mat on a gym floor — matching the "Dead Bug" mat style
already used for Day 3 (`docs/images/d3/11-dead-bug.jpg`). Camera angle and
mat framing vary slightly per exercise to hint at the movement without ever
showing a person. Three of these five (Dead Bug, Side Plank, Bird Dog) repeat
Core A's exercises — reuse those same generated images if you'd rather not
regenerate near-duplicates; separate prompts are included below for
completeness.

**No people:** every image shows the equipment/mat only — empty and
unoccupied, like a clean product/catalog photo. No person, model, silhouette,
or mannequin in any image.

**Copyright:** these are AI-generated illustrations, free of third-party
rights — safe to bundle and publish with the app.

**Shared style (applies to every prompt below):** Photorealistic landscape
photo (16:9), clean modern gym, bright even natural lighting with soft
daylight from large windows, shallow depth of field, encouraging professional
fitness aesthetic. Ultra-detailed, high resolution, realistic materials —
matte rubber or foam exercise mat, clean floor. The mat is the sole subject,
empty and unoccupied, centered and fully in frame.

**Shared negative / avoid (append to every prompt):** any person, human
figure, model, silhouette, mannequin, or body part; text, watermarks, logos,
cartoon or 3D-render look, cluttered background, distracting bystanders.

Prompts are numbered `CB-01 … CB-05`.
